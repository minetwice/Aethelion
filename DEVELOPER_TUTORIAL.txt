================================================================================
AETHELION - DEVELOPER INTEGRATION & ANIMATION REGISTRATION TUTORIAL
================================================================================
Plugin Name: Aethelion
Author: Twicefear
Base Package: com.twicefear.aethelion
Purpose: Custom Blockbench (.bbmodel / JSON) emotes, animations, body scaling &
         no-resource-pack custom particle design library

--------------------------------------------------------------------------------
1. ADDING AETHELION TO YOUR PLUGIN PROJECT
--------------------------------------------------------------------------------

A) plugin.yml Dependencies
Add Aethelion as a dependency or soft dependency in your plugin.yml:

depend: [Aethelion]
# OR for soft dependency:
softdepend: [Aethelion]

B) build.gradle Configuration
Add Aethelion JAR as a compileOnly dependency or local jar dependency:

dependencies {
    compileOnly files('libs/Aethelion-1.0.0.jar')
}


--------------------------------------------------------------------------------
2. HOOKING INTO THE AETHELION API
--------------------------------------------------------------------------------

In your Java plugin's onEnable() or command listener:

import com.twicefear.aethelion.api.EmoteAPI;
import org.bukkit.Bukkit;

public class MyPlugin extends JavaPlugin {
    private EmoteAPI emoteAPI;

    @Override
    public void onEnable() {
        if (Bukkit.getPluginManager().isPluginEnabled("Aethelion")) {
            this.emoteAPI = (EmoteAPI) Bukkit.getPluginManager().getPlugin("Aethelion");
            getLogger().info("Successfully hooked into Aethelion!");
        } else {
            getLogger().warning("Aethelion plugin not found!");
        }
    }

    public EmoteAPI getEmoteAPI() {
        return emoteAPI;
    }
}


--------------------------------------------------------------------------------
3. DYNAMICALLY REGISTERING ANIMATIONS FROM YOUR OWN PLUGIN
--------------------------------------------------------------------------------

You can bundle Blockbench animation JSON / .bbmodel files inside your plugin's
`src/main/resources/animations/` folder and register them dynamically at runtime!

Example 1: Registering from InputStream (Plugin JAR Resource)
--------------------------------------------------------------
InputStream stream = getResource("animations/wave.json");
if (stream != null) {
    boolean success = emoteAPI.registerAnimation("custom_wave", stream);
    if (success) {
        getLogger().info("Registered 'custom_wave' animation successfully!");
    }
}

Example 2: Registering from JSON String
----------------------------------------
String jsonContent = """
{
    "animations": {
        "custom_dance": {
            "loop": true,
            "length": 40,
            "bones": {
                "head": {
                    "rotation": {
                        "keyframes": [
                            {"t": 0, "x": 0, "y": 0, "z": 0},
                            {"t": 20, "x": 15, "y": 0, "z": 0}
                        ]
                    }
                }
            }
        }
    }
}
""";

emoteAPI.registerAnimation("custom_dance", jsonContent);

4. CUSTOM PARTICLES & TEXTURE DESIGN (WITHOUT RESOURCE PACKS)
--------------------------------------------------------------------------------

Aethelion allows developers to define custom particles with custom RGB colors,
dust sizes, item textures, block crunch textures, velocity, offset and speeds
directly via JSON files inside their plugin without requiring any client resource packs!

Example JSON particle file (`src/main/resources/particles/magic_aura.json`):
```json
{
  "particle": {
    "type": "REDSTONE",
    "color": { "r": 120, "g": 255, "b": 220 },
    "size": 1.5,
    "count": 10,
    "offsetX": 0.3,
    "offsetY": 0.5,
    "offsetZ": 0.3,
    "speed": 0.02
  }
}
```

Or an item crack particle using item material textures (`particles/fire_spark.json`):
```json
{
  "particle": {
    "type": "ITEM_CRACK",
    "material": "BLAZE_POWDER",
    "count": 15,
    "offsetX": 0.2,
    "offsetY": 0.4,
    "offsetZ": 0.2,
    "speed": 0.05
  }
}
```

Registering & Spawning Custom Particles in Java:
-----------------------------------------------

// Register particle design from plugin resource stream
InputStream particleStream = getResource("particles/magic_aura.json");
emoteAPI.registerParticle("magic_aura", particleStream);

// Spawn on a player
emoteAPI.spawnParticleOnPlayer(player, "magic_aura");

// Spawn at any Location in the world
emoteAPI.spawnParticle(player.getLocation(), "magic_aura");


--------------------------------------------------------------------------------
5. PLAYING AND STOPPING ANIMATIONS ON PLAYERS
--------------------------------------------------------------------------------

// Play an animation on a player
boolean playing = emoteAPI.playEmote(player, "custom_wave");

// Check if player is currently playing an emote
boolean isEmoting = emoteAPI.isEmoting(player);

// Stop a specific emote
emoteAPI.stopEmote(player, "custom_wave");

// Stop all active emotes on player
emoteAPI.stopAllEmotes(player);


--------------------------------------------------------------------------------
6. BODY PART SCALING (HEAD, BODY, ARMS, LEGS)
--------------------------------------------------------------------------------

// Scale player's head to 2.0x size (Clamped between 0.2 and 3.125)
emoteAPI.setScale(player, "head", 2.0f);

// Get current bone scale
float headScale = emoteAPI.getScale(player, "head");

// Reset specific bone scale
emoteAPI.resetScale(player, "head");

// Reset all bone scales on player
emoteAPI.resetScale(player, null);


--------------------------------------------------------------------------------
7. UTILITY METHODS
--------------------------------------------------------------------------------

// List all registered and available animations & particles
List<String> animations = emoteAPI.getAvailableEmotes();
List<String> particles = emoteAPI.getAvailableParticles();

// Prompt resource pack to a player
emoteAPI.promptResourcePack(player);

// Reload animation cache
emoteAPI.reloadAnimations();


--------------------------------------------------------------------------------
SUMMARY
--------------------------------------------------------------------------------
With Aethelion, third-party plugins can supply custom animation JSON files AND
custom particle designs without client-side resource packs! Simply call
`registerAnimation()` and `registerParticle()`, then play them on players!
