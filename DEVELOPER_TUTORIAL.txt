PART 1: WHAT CAN YOU BUILD WITH AETHELION? (PLUGIN IDEAS)
================================================================================
With Aethelion as your core server library, you can build a wide array of high-level
Minecraft plugins without writing custom entity rendering or packet math from scratch:

1. Custom Emotes & Social Plugins:
   - Player dance emotes, wave animations, sitting/sleeping poses.
   - Interactive couple emotes (handshakes, high fives, hugs).

2. RPG & MMO Skill/Magic Plugins:
   - Custom spell casting animations (e.g. raising arms, levitating).
   - Dynamic magical particle halos, spiral energy beams, custom aura effects.

3. Custom Bosses, Pets & Mounts (No Resource Pack Required):
   - Import custom 3D OBJ or JSON models directly into your plugin JAR.
   - Render custom mob/boss models using Display Entities automatically.

4. Body Transformation & Scaling Plugins:
   - Titan/Giant spells (scaling body parts or whole player up to 3.125x).
   - Ant-man / Dwarf transformations (shrinking player down to 0.2x).
   - Big Head mode or Custom Chibi proportions.

5. Custom Particle & Visual FX Plugins:
   - Weapon trails, wing particle FX, custom level-up celebrations.
   - Dynamic RGB color dust and material particle explosions.

================================================================================
PART 3: CRITERIA FOR DEVELOPERS
================================================================================

1. Model Integration Criteria:
   - Supported Formats: `.bbmodel`, `.json`, `.obj` + `.mtl`.
   - No Client Resource Pack Needed: Models are rendered on the server using
     Display Entities (ItemDisplay/BlockDisplay/TextDisplay) or NMS packets.
   - Bone Naming Convention: For player emote body attachments, use standard bone names:
     `head`, `body`, `left_arm`, `right_arm`, `left_leg`, `right_leg`.

2. Particle Criteria:
   - No Client Resource Pack Needed!
   - Particles use vanilla particle options (Dust RGB, Dust Size, Item Textures, Block Textures).
   - Procedural Particle Code: Developers can register 1-tick step callbacks in Java
     to render mathematical shapes (spirals, circles, wings, vectors).


================================================================================
PART 4: STEP-BY-STEP CODE TUTORIAL FOR DEVELOPERS
================================================================================

1. HOOKING INTO AETHELION
-------------------------
Add to your plugin.yml:
  depend: [Aethelion]

Java Hook Code:
```java
import com.twicefear.aethelion.api.EmoteAPI;
import org.bukkit.Bukkit;

EmoteAPI api = (EmoteAPI) Bukkit.getPluginManager().getPlugin("Aethelion");
```

2. REGISTERING BBMODEL / JSON ANIMATIONS FROM YOUR PLUGIN JAR
-------------------------------------------------------------
Put `dance.json` inside your plugin's `src/main/resources/animations/`:
```java
InputStream stream = getResource("animations/dance.json");
api.registerAnimation("my_dance", stream);

// Play on player:
api.playEmote(player, "my_dance");
```

3. REGISTERING & RENDERING OBJ + TEXTURE MODELS
------------------------------------------------
Put `boss.obj` and `boss.mtl` in your plugin's resources:
```java
InputStream objStream = getResource("models/boss.obj");
InputStream mtlStream = getResource("models/boss.mtl");

api.registerUniversalObjModel("custom_boss", objStream, mtlStream);
```

4. CREATING CUSTOM PARTICLES VIA JSON (NO RESOURCE PACK)
--------------------------------------------------------
Put `aura.json` in your resources:
```json
{
  "particle": {
    "type": "REDSTONE",
    "color": { "r": 255, "g": 100, "b": 200 },
    "size": 1.8,
    "count": 12,
    "offsetX": 0.4,
    "offsetY": 0.6,
    "offsetZ": 0.4,
    "speed": 0.01
  }
}
```

Java code to register and spawn:
```java
api.registerParticle("custom_aura", getResource("particles/aura.json"));
api.spawnParticleOnPlayer(player, "custom_aura");
```

5. PROCEDURAL CODE-BASED PARTICLES (CUSTOM SHAPES & DYNAMICS IN CODE)
---------------------------------------------------------------------
You can create custom mathematical particles (e.g. rotating particle spiral):
```java
api.registerCustomCodeParticleEffect("spiral_halo", 40 /* 40 ticks = 2 sec */, (origin, tick, effect) -> {
    double radius = 1.0;
    double angle = tick * 0.3;
    double x = radius * Math.cos(angle);
    double z = radius * Math.sin(angle);
    double y = (tick * 0.05);

    Location particleLoc = origin.clone().add(x, y, z);
    particleLoc.getWorld().spawnParticle(Particle.END_ROD, particleLoc, 1, 0, 0, 0, 0);
});

// Run particle effect on player:
api.runParticleEffectOnPlayer(player, "spiral_halo");
```

6. BODY PART SCALING
--------------------
```java
// Make player head 2.5x bigger
api.setScale(player, "head", 2.5f);

// Reset scale back to normal
api.resetScale(player, "head");
```
